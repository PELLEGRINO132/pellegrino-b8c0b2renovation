# Pellegrino Rénovation

Site vitrine de Pellegrino Rénovation, plâtrier-staffeur à Condom (Gers) : plâtrerie, staff et moulures, placo, isolation, carrelage et peinture.

Site en ligne : https://pellegrino-b8c0b2renovation.netlify.app/

## Contenu du dépôt

- `index.html`, `services.html`, `realisations.html`, `restaurations.html`, `contact.html` : les pages du site
- `style.css` : feuille de style commune
- `images/` : photos de chantiers
- `robots.txt`, `sitemap.xml` : référencement

## Mise à jour du site

Le site se met à jour automatiquement sur Netlify à chaque modification enregistrée (« commit ») sur la branche `main`.
