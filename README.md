# Pellegrino Rénovation

Site vitrine de Pellegrino Rénovation, plâtrier-staffeur à Condom (Gers).

Site en ligne : https://pellegrino-b8c0b2renovation.netlify.app/

## Contenu

- `index.html`, `services.html`, `realisations.html`, `devis.html`, `contact.html` : les pages
- `style.css` : la feuille de style commune
- `script.js` : menu mobile, agrandissement des photos, envoi des formulaires
- `images/` : photos, classées par chantier
- `robots.txt`, `sitemap.xml` : référencement

Le site se met à jour automatiquement sur Netlify à chaque modification enregistrée sur la branche `main`.
